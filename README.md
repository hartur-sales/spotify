# 🎵 Hartasfy - Spotify Clone

Um clone da interface do Spotify desenvolvido para praticar e aprimorar conhecimentos de frontend.

[English version below](#english-version)

## 📋 Sobre o Projeto

Este projeto é uma recriação da interface do Spotify com o objetivo de praticar habilidades de desenvolvimento frontend. O "Hartasfy" replica a aparência e estrutura básica do Spotify, incluindo navegação lateral, grade de artistas e álbuns populares.

## ✨ Funcionalidades

- 🎨 Interface responsiva inspirada no Spotify
- 📱 Barra lateral com navegação
- 🎤 Grade de artistas populares
- 💿 Grade de álbuns populares
- 🔍 Barra de pesquisa (interface)
- 🌐 Seletor de idioma
- 📢 Banner promocional do Premium

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura da página
- **CSS3** - Estilização e layout
- **JavaScript (Vanilla)** - Funcionalidades dinâmicas
- **Font Awesome** - Ícones
- **Google Fonts (Montserrat)** - Tipografia

## 🚀 Como Usar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/hartur-sales/spotify.git
   ```

2. **Navegue até a pasta do projeto**
   ```bash
   cd spotify
   ```

3. **Abra o arquivo `index.html` no navegador**
   - Você pode simplesmente dar um duplo clique no arquivo `index.html`
   - Ou usar um servidor local como Live Server (extensão do VS Code)
   - Ou usar Python: `python -m http.server 8000`

4. **Explore a interface!**

- 📱 Sidebar with navigation
- 🎤 Popular artists grid
- 💿 Popular albums grid

- 🌐 Language selector
- 📢 Premium promotional banner
